# Análisis numérico

Calcular con números de máquina y saber cuánto se equivoca el resultado: errores y punto flotante, raíces de ecuaciones, interpolación y aproximación, derivación e integración numéricas, diferencias finitas, sistemas lineales y problemas de valor inicial.

**Ver en línea:** https://aaramirez.github.io/mate-analisis-numerico/
